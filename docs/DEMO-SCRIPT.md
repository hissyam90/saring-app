# Skrip Demo

Dokumen ini sudah digantikan oleh dua naskah yang lebih akurat:

- **[NASKAH-DEMO-VIDEO.md](NASKAH-DEMO-VIDEO.md)** — naskah video demonstrasi
  berdurasi maksimal 5 menit untuk dikirim kepada juri, lengkap dengan pembagian
  waktu per segmen, data demo fiktif, dan urutan klik.
- **[PANDUAN-PRESENTASI.md](PANDUAN-PRESENTASI.md)** — naskah demo lengkap per
  menu untuk sesi presentasi langsung, memuat tujuan, aksi demo, teks yang dibaca,
  serta materi tanya jawab juri.

Naskah lama di dokumen ini tidak lagi akurat — antara lain memakai tagline lama
("Berhenti sebentar. Periksa sinyalnya.") dan menyebut aplikasi berjalan tanpa
akun, padahal Komunitas, artikel, dan admin sudah memerlukan akun. Versi lama
tetap tersedia pada riwayat Git.
